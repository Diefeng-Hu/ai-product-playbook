# inbox — 机器写入区

[digital-me](https://github.com/yaowenhu-pm/digital-me) 的每日沉淀管线（每天 21:30）自动把当日语料里"值得沉淀的内容"写到这里，一天一个文件（`YYYY-MM-DD.md`），每条带观点、原文和语料出处。

**这里是候选区，不是正文。** 工作流：定期翻 inbox → 跨场景成立、能改变未来决策的内容整理进 `model/`、`platform/` 或 `applications/` → 可直接复用的模板进入 `toolkit/` → 单次实践进入 `cases/` → 删除已处理的 inbox 文件。机器只进不出，出口永远是人工判断。
